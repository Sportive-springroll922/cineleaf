# Privacy

Cineleaf is local-first by design.

- No account, login, subscription, API key, remote server, advertisement, analytics, telemetry, tracking, or data collection.
- No media, project data, filename, performance timing, or diagnostic entry is uploaded by Cineleaf.
- Security-scoped bookmarks may be stored inside a project so macOS can reopen files the user selected.
- Derived thumbnails and waveform peaks may be stored in a bounded local cache. They can be cleared in Settings without deleting projects or source media.
- Local diagnostic timings contain operation categories and elapsed time, not media content or remote identifiers.
- Exported videos contain the content the user deliberately placed on the timeline and no Cineleaf watermark.

The operating system, GitHub, build tools, or distribution website may have their own privacy practices; those are outside the Cineleaf application.
